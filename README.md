## Cara Menggunakan Playlist M3U

### 1. Smart TV / Android TV / STB Android Box
1. Install aplikasi **TiviMate** atau **Televizo** dari Google Play Store (atau **IPTV Smarters Pro** resmi melalui situs pengembangnya jika diperlukan).
2. Pilih **Add Playlist** → **M3U Playlist** (URL).
3. Tempelkan URL `playlist.m3u` di atas, lalu tunggu daftar channel termuat.

### 2. HP Android & iPhone (iOS)
1. Install **VLC for Mobile** atau aplikasi IPTV player pilihan Anda dari Play Store / App Store.
2. Pilih menu **Network Stream** / **Add Playlist URL**, lalu tempelkan URL `playlist.m3u` di atas.

### 3. PC / Laptop (Windows, macOS, Linux)
1. Buka **VLC Media Player**.
2. Tekan `Ctrl + N` (Windows/Linux) atau `Cmd + N` (macOS), tempelkan URL `playlist.m3u`, lalu klik **Play**.
3. Tekan `Ctrl + L` (Windows/Linux) atau `Option + Cmd + P` (macOS) untuk membuka daftar channel.
